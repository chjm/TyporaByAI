Project Brief: MiniMark
A minimalist Markdown editor, born from AI — and a social experiment.

🧪 What is this?
This is a lightweight, AI‑generated Markdown editor that mimics the core writing experience of apps like Typora — but stripped down to the absolute essentials.
It was created in a few hours using LLM‑assisted coding, not as a replacement, but as a provocation and a test.

🤔 Why does it exist?
I love tools like Typora. They’re beautiful, thoughtful, and have shaped how many of us write.
But lately, I’ve been watching the software landscape shift — AI can now scaffold functional clones of established apps with surprising speed. This project is my way of asking:

“What happens when a tool that took years to craft can be re‑created in an afternoon, by one person with a prompt?”

I’m not claiming this is better. It’s not. It lacks polish, plugins, themes, and years of UX refinements. But it works — and that alone makes me uneasy.

🙏 A note on respect & intent
This project is in no way meant to disparage, replace, or mock Typora or its developers.
I have immense respect for the craft and care that went into that software. If anything, this experiment highlights how much invisible value lies in the details — details that AI cannot replicate.

I’m publishing this not to compete, but to learn:

How will the open‑source community react?

Will people see it as a novelty, a threat, or a distraction?

What does it say about the future of “original” vs “generated” software?

🚀 What I’m testing
By putting this on GitHub, I want to observe:

Forks & usage — does anyone actually want this?

Issues & PRs — will the community improve it, or ignore it?

Feedback tone — curiosity, hostility, indifference?

Ethical debates — does “AI‑generated” change the perception of open source?

⚠️ Disclaimer
This is not a polished product. It’s a prototype, intentionally rough.

I do not claim copyright over the UI layout (which is inspired by many existing editors).

All generated code has been reviewed and adjusted by me; it’s not blindly copied from training data.

If the original Typora team or any developer feels this crosses a line, I will take it down immediately — just open an issue or email me.

🧭 What happens next?
I’ll leave this repo public for 90 days, then share a summary of the reactions.
No monetization, no ads, no analytics — just raw curiosity.

Star ⭐ if you’re curious, fork 🍴 if you want to experiment, and comment 💬 if you have thoughts — I genuinely want to hear them.
